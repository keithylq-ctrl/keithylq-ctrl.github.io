会写代码和理解模型是两件不同的事。我可以用 Python 处理数据，但在准备数据分析竞赛时，发现自己需要更系统地回答：模型学到了什么，又如何知道它在新数据上仍然可靠？

我打算从一张简单的地图开始：**问题定义 → 数据理解 → 基线方法 → 模型训练 → 验证 → 解释和表达**。

先建立这条完整路径，再逐步进入回归、分类、预测和更复杂的方法。每学到一种模型，我都想用一个真实例子回答：它适合什么问题、怎样判断有效、又会在哪些情况下失效。
